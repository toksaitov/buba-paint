# Experiments

This directory holds derived forensic and calibration work. It is safe to regenerate from primary run DBs and logs, but many outputs are still useful context.

Preferred naming:

* `run-XXX-topic-NNN`
* examples: `run-012-forensics-001`, `run-018-parity-002`

Keep experiment-specific scripts, CSVs, scratch DBs, and notes inside the experiment directory. Do not place run-specific planning documents in the repository `docs/` root.

Historical directories with older naming remain for traceability. Do not use them as naming examples for new work.
