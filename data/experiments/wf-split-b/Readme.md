# WF Split B

Legacy walk-forward split experiment workspace.

Contents are small SQLite replay output DBs:

* `baseline.db`
* `c1.db`
* `c2.db`
* `c3.db`
* `c4.db`

These files are derived outputs used for an older calibration comparison. The directory predates the current `run-XXX-topic-NNN` naming rule and is kept only for historical traceability.

Do not use this directory as a template for new experiments.
