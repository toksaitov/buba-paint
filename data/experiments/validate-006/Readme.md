# Validate 006

Legacy validation workspace for run 006 era backtest experiments.

Contents are small SQLite replay output DBs:

* `full-range.db`
* `latarb-only.db`
* `latarb-only-v2.db`
* `v05-params.db`

These files are derived outputs, not primary evidence. The directory predates the current `run-XXX-topic-NNN` naming rule and is kept only for historical traceability until its conclusions are migrated or deliberately pruned.

Do not use this directory as a template for new experiments.
