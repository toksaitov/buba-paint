# Backfill Cache

This directory stores cached HTTP responses used by historical upgrade and verification workflows.

The cache is derived data. It can be regenerated by `upgrade-history` and related backfill commands, but keeping it avoids repeated Gamma or CLOB API requests when rebuilding historical metadata.

Contents:

* `gamma/`: cached Gamma market metadata by BTC 5 minute slug.
* `clob/`: reserved cache location for CLOB backfill responses. It is currently empty.

Do not treat this directory as primary run evidence. Primary run DBs and logs live under `runs/`.
